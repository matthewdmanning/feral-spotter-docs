# cats-annotate-flow sprint context (#167-174, #177)

## 1. Relevant code locations

**Screens**

- `src/screens/submission/create/index.tsx` — **Cat List** screen (`CreateSubmissionScreen`). `handleAddCat` routes to `/submission/annotate` (annotate-first, per ADR 0004). **No auto-skip-when-empty logic present** (#173 not yet implemented — verified directly, no on-mount `cats.length === 0` navigation exists).
- `src/screens/submission/annotate/index.tsx` + `index.styles.ts` — **annotate** screen (`AnnotateScreen`). Uses `useAnnotatePass()`. Hardware back (`useBackHandler`) is the only mid-pass exit, calls `clearActiveCat()`. Bottom bar has Back / "Not in Photo" pill (disabled when `!activeCatId`) / "Boxing Complete". Dots strip renders 3-way status (`located`/`not-in-photo`/pending) via `theme.colors.accent`/`warning`/`muted`.
- `src/screens/submission/cats/index.tsx` + `index.styles.ts` + `constants.ts` — **Cat Form** screen (`CatObservationScreen`, title toggles "Observed Cat"/"Edit Cat"). Computes `catId = existingCat?.local_id ?? activeCatId` and passes to `CatForm`. `annotationEnabled` no longer passed to `CatForm` (was only for the now-deleted photo selector), still passed to `useCatSubmit`.

**Hooks/stores**

- `src/hooks/useBoundingBoxStore.ts` — persisted Zustand store, `${cat_id}:${photo_local_id}` keying. Has `boxes`, `lastBoxes`, and the new **`absences: Record<string, true>`**. `addBox`/`markAbsent` are mutually exclusive (each clears the other's entry at the same key, one atomic `set()`). Also: `getBoxesForPhoto`, `removeBoxesForPhoto` (photo-removal cleanup, #177), `getBoxedPhotoIds`, `getFirstBox` (both added in #172, key-insertion-order based). Migration `v1→v2` wipes old canvas-relative box data.
- `src/hooks/useActiveCatFlow.ts` — composes `useActiveCatFlowStore` + `useBoundingBoxStore`. Exports `PhotoPassStatus = 'pending' | 'located' | 'not-in-photo'`. Handlers: `handleBoxConfirmed` (mints `randomUUID()` cat id only if none active — the "first box declares a cat" mechanic), **`handleNotInPhoto`** (no-ops if `!activeCatId`, else `markAbsent`), `handleBoxingComplete` (routes to `/submission/cats` if a cat is active, else `router.back()`), `clearActiveCat`. `getPhotoStatus` subscribes directly to the `boxes`/`absences` slices (not the stable `getBoxes` fn) — noted gotcha: must subscribe to slices for correct re-renders.
- `src/hooks/useActiveCatFlowStore.ts` — persisted (AsyncStorage), holds only `activeCatId: string | null`. Split into its own file deliberately for independent `jest.mock`-ability.
- `src/hooks/useAnnotatePass.ts` — screen-local, non-persisted. Owns full photo pool (`usePhotoStore`), carousel index/ref, `handleConfirmBox` (advances unless last photo), **`handleNotInPhoto`** (mirrors `handleConfirmBox`'s advance logic), `handlePrevPhoto`, `handleLongPressRemove` (now also calls `removeBoxesForPhoto` — #177 fix).
- `src/hooks/useCatForm.ts` — `photoIds`/`handleTogglePhoto` removed (#172).
- `src/hooks/useCatSubmit.ts` — `buildCat`'s `photo_local_ids` derived via `getBoxedPhotoIds(localId)`, falls back to `existingCat.photo_local_ids` if the derived list is empty (protects pre-#170 cats / migration wipes). `saveLabel` reads `getBoxedPhotoIds`.

**Components**

- `src/components/organisms/AnnotateCarouselItem.tsx` + `.styles.ts` — single carousel slide; `catId` prop renamed `activeCatId` (nullable); `onConfirm: (box) => void` — surfaces the box, doesn't persist it itself (caller does, since the very first box has no cat id yet).
- `src/components/organisms/CatForm.tsx` + `.styles.ts` — dropped `CatPhotoSelector`/`photoSection` entirely (#172); new `catId: string | null` prop drives the inset crop.
- `src/components/organisms/CatFormInsetCrop.tsx` + `.styles.ts` — **placeholder** inset crop (ticket #172's scope, not #174's real component). Reads `getFirstBox(catId)` + its photo, computes a cover-style crop transform on `Image.onLoad`, renders in a fixed 88×88 `overflow:hidden` box. Handles degenerate zero-area box by falling back to full-frame-around-center. No pop-out/slide-to-side interaction yet — that's #174.
- `src/components/organisms/CatPhotoSelector.*` — **deleted** (confirmed via glob; only stale `coverage/lcov-report/...` HTML remains).
- `docs/design/prototypes/2026-08-06-issue168-inset-crop.html` — the **real** inset-crop prototype (3 variants A/B/C), lives under `docs/design/prototypes/`, merged from `matthewdmanning/issue168` branch into `sprint/cat-annotate-flow` at commit `310c6e0`. Not yet wired into actual app components — #174 will do that.

**Types**

- `PhotoPassStatus` type lives in `src/hooks/useActiveCatFlow.ts` (not a separate types file): `'pending' | 'located' | 'not-in-photo'`.
- `src/types/BoundingBox` — `BoundingBox` shape (`lowerLeftX/Y`, `upperRightX/Y`, `id`, `cat_id`, `photo_local_id`).

**Tests**

- `src/hooks/__tests__/useActiveCatFlow.model.test.ts` — xstate model test (`getPathsFromEvents`), mocks both `useActiveCatFlowStore` and `useBoundingBoxStore` with real non-persisted `zustand.create()` instances (avoids the documented `react-test-renderer` + persisted-store-rehydration crash). Covers `BOX_CONFIRMED`, `NOT_IN_PHOTO` (self-loop on `annotating` only), `BOXING_COMPLETE`, mutual-exclusivity round trip, no-active-cat-no-op guard.
- `src/hooks/__tests__/useBoundingBoxStore.test.ts` — pure reducer test (no rendering) for `removeBoxesForPhoto` (#177): multi-cat sweep, absences swept, `lastBoxes` cleared, other-photo untouched.
- **No test coverage exists** for: `useAnnotatePass`, the `annotate` screen itself, `CatFormInsetCrop`'s transform math, `useCatForm`/`useCatSubmit`/`CatForm` (all repeatedly flagged in implementation docs as pre-existing/accepted gaps, not this sprint's job to fill unless a ticket calls for it).
