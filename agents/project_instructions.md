# Agent Instructions Index

Read _only_ the sections and linked documents required for the task you were
instructed to perform. Follow an explicitly required reference before acting;
otherwise, do not load unrelated guidance merely because it is listed here.
Big tasks can legitimately match several rows; read each match, don't stop at the first. If you open a link that does not contain any information relevant to your task, alert the user -- include the reason you chose to open the link.

## Template routing

- New feature or sprint implementation note -> [documentation.md](documentation.md) -> [[templates/feature-implementation-draft|feature implementation draft]]
- New or updated UI/UX design decision -> [using-design-decisions.md](using-design-decisions.md) -> [[templates/design-decision-template|design decision template]]

For manual Android MVP QA, read [qa_checklist.md](../qa_checklist.md) for the canonical end-to-end coverage across launch, permissions, capture, annotation, submission, recovery, network, and device conditions.

Repository layout/dev commands (`development.md`) aren't written yet. For branch-commit-PR _hygiene_, use the global CLAUDE.md git-workflow rules; for git/GitHub _mechanics_, see [git.md](git.md).

## File Format

Project format: YYYY-MM-DD-{activity_name}
The activity_name is the name of the sprint, if one is active, or the branch, if not main. If the activity name is not known, ask the user.

Exception: `docs/adr/`, `docs/planning/`, `docs/design-decisions/` are exempt — each file tracks its own last-updated date inside itself, not in the filename.
